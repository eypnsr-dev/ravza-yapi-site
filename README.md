# Ravza Yapı — static website

Modern responsive website for Ravza Yapı Nalbur, renovation and decoration services.

## Scope on the site
- Hardware and building material sales at the Gaziosmanpaşa / Karlıtepe shop.
- Apartment renovation, painting and decoration across Istanbul.
- Furniture and kitchen-cabinet painting with Bianca Stella.

## Preview
Open `index.html` or start a local server from this folder with `python -m http.server 8000`, then visit `http://localhost:8000`.

## Publishing
Prepared for GitHub Pages and `www.ravzayapinalbur.com`. Configure Pages to deploy from the main branch root. At the domain DNS provider, point `www` to `<github-username>.github.io` and configure the apex domain A records according to GitHub Pages' current documentation. Keep domain registration active. Enable HTTPS in Pages settings after DNS propagates.

## SEO / local discovery
Includes Turkish page title and description, canonical and social metadata, LocalBusiness structured data for the Gaziosmanpaşa store, separate Istanbul-wide renovation service area, phone, address, Instagram sameAs, sitemap, and robots file. Business hours are omitted pending confirmation.
